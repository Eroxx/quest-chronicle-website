Use Quest Chronicle with Claude

On the Mac, Claude, Codex and other AI apps can read your game library and play history, answer questions about it, and log sessions, change statuses, add and tag games and build lists for you. You set it up once.

This works with Quest Chronicle on a Mac only. The iPhone and iPad apps can't be connected, but anything the AI app changes reaches them through iCloud like any other change.

Set it up

  1. Have an AI app on your Mac. The Claude app (from claude.ai/download), Claude Code, Codex, or any app that supports MCP servers.
  2. Open Quest Chronicle's setup. In Quest Chronicle on the Mac, go to Settings, then AI Apps (Help, then Use Quest Chronicle with Claude, goes there too). It has a Copy Setup button for each app, with the exact text shown under it.
  3. Add it to your AI app, as below for the app you use.
  4. Ask about your games in a new chat.

The setup names where Quest Chronicle is on your Mac. If it's in your Applications folder, the text is exactly what's below. Copying it from Settings is safest, since it always has the right place.

The Claude app (Claude Desktop)

  1. In Claude, choose Settings, then Developer, then Edit Config. That shows a file called claude_desktop_config.json.
  2. If the file is empty or holds only {}, replace it with this: 
    {
  "mcpServers": {
    "quest-chronicle": {
      "command": "/Applications/Quest Chronicle.app/Contents/MacOS/Quest Chronicle",
      "args": ["--mcp"]
    }
  }
}
    If it already lists other servers under "mcpServers", add just the "quest-chronicle": { … } part beside them, with a comma between entries.
  3. Save the file, then quit Claude completely (Command-Q) and open it again. Claude reads this file only when it starts.

Claude Code

Paste this into Terminal and press Return, once:

claude mcp add --scope user quest-chronicle -- "/Applications/Quest Chronicle.app/Contents/MacOS/Quest Chronicle" --mcp

Every new Claude Code session can then use it. claude mcp list shows it.

Codex

Paste this into Terminal and press Return, once:

codex mcp add quest-chronicle -- "/Applications/Quest Chronicle.app/Contents/MacOS/Quest Chronicle" --mcp

Another app that supports MCP

Add a local (stdio) server with the command /Applications/Quest Chronicle.app/Contents/MacOS/Quest Chronicle and the one argument --mcp.

What to ask

Ask in your own words. Some things people ask:

  • “What have I played most this month?”
  • “Log two hours of Hades II for last night.”
  • “Which short Switch games have I never started?”
  • “Make a smart list of Backlog games under 10 hours.”
  • “Tag every Zelda game as Zelda.”
  • “Which games am I closest to 100% achievements on?”
  • “Show me that list in Quest Chronicle.”

What it can do

  • Read: your games with their statuses, consoles, genres, notes, tags and lists; your play sessions; play statistics for any period; Steam, Xbox and PlayStation achievements.
  • Change: log a play session, change a game's status, add a game, edit a game's notes or genre, add games to a list or take them out, create a list or a smart list, and tag or untag games.
  • Show: bring Quest Chronicle forward on a game or a list.

Every change goes through Quest Chronicle, so it syncs to your other devices like one you made, and you can ask it to undo its last change. It can't delete a game or a list. The one thing it can remove is a single play session, and it asks you which one first.

Questions

Does Quest Chronicle have to be open?

No. When the AI app needs it, it opens Quest Chronicle in the background, out of your way.

Does my library go to Anthropic or OpenAI?

Quest Chronicle sends nothing to them by itself. What the AI app reads to answer you becomes part of that conversation, under that company's own privacy policy. Nothing is connected until you add the setup, and removing it from your AI app disconnects it. The privacy policy says more.

It doesn't show up in my AI app.

Quit the AI app completely and open it again: it reads its setup only when it starts. If you moved Quest Chronicle to another folder, copy the setup again from Settings, since it names where the app is. In Claude's Edit Config file, a missing comma or bracket stops every server loading; Claude says so in Settings, then Developer.

How do I remove it?

Claude app: delete the "quest-chronicle" entry from the config file and restart Claude. Claude Code: claude mcp remove quest-chronicle. Codex: codex mcp remove quest-chronicle.
